# Shared infrastructure

Build configuration (MSBuild props and targets, code analysis rulesets, `.editorconfig`, `.gitattributes`) and shared helper sources used by FreeDotnetImageSharp.

This directory was vendored from [SixLabors/SharedInfrastructure](https://github.com/SixLabors/SharedInfrastructure) at commit `59ce17f` (Apache License 2.0) and has since been modified. See the [NOTICE](../NOTICE) file in the repository root.

Note: `.editorconfig` and `.gitattributes` in this directory are copied to the repository root on every build. Edit them here, not in the root.
